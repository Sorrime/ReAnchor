# ReAnchor

> 当外部观测逐渐减弱，一个内部世界模型会走向哪里？
>
> 一个关于观测退锚、内部生成、情境混合与重新锚定的计算实验项目。

---

## 项目状态

ReAnchor 目前处于灵感记录和基础学习阶段。

现阶段还没有得到任何关于人类意识、梦境或物理现实的实验结论。本仓库首先用于保存项目最初的灵感，并逐步把其中可以检验的部分转化为计算实验。

---

# 灵感来源

## 一次关于谷子店的梦

这个项目来自我曾经做过的一场梦。

我梦见自己正在逛一家谷子店，并且想购买一个御坂美琴的亚克力立牌。

梦里的我知道自己正处在那家店里，同时又保留着关于现实世界的部分认识。我向店员询问：

> 能不能把我在这里买到的谷子，寄到我现实中的地址？

后来我醒了。

现在回想起来，这个问题在梦境内部似乎并没有立刻显得荒谬。梦里的我一方面接受了谷子店所在的世界，另一方面又记得现实地址的存在，并试图通过“邮寄”在两个世界之间建立联系。

ReAnchor 最初就是从这个问题开始的：

> 为什么梦中的我能够同时想到梦里的商店和现实中的地址，却没有意识到这两个情境之间可能并不存在可行的物理通道？

## 醒来后的原始联想

> 本节记录的是项目诞生时未经验证的原始想法，不代表本项目已经接受的科学结论。

醒来以后，我产生了一个带有科幻和哲学色彩的猜想：

假如人的意识在某种意义上扮演了“观测者”的角色，那么人在清醒时，会不会因为感官不断提供外部信息，而被稳定地锚定在同一个现实模型中？

当人进入睡眠后，外部感官信息对意识状态的约束减弱，内部世界模型开始更多地依赖记忆、预测、情绪和联想。在这种情况下，意识会不会看见一些清醒状态下无法进入的可能世界？

我当时进一步联想到：

- 梦境是否可能与某种“平行宇宙”有关；
- 意识是否可能是一种特殊的“观测者”；
- 睡眠时感官观测的减弱是否与“退相干”或世界分支有关；
- 梦中的信息能否以某种方式与现实世界建立联系。

这些想法是项目的原始灵感，但目前没有证据表明：

- 梦境是真实的平行宇宙；
- 意识是量子力学中必需的观测者；
- 睡眠会阻止宏观大脑系统发生退相干；
- 梦境可以在不同量子分支之间传递信息或物体。

因此，ReAnchor 不把“梦是平行宇宙”作为已经成立的物理假设，而是保留这个想法作为项目起点，并尝试提取其中能够被计算和实验检验的问题。

---

# 从梦境到计算问题

与其直接询问“梦是不是平行宇宙”，ReAnchor 首先研究一个范围更小、能够进行实验的问题：

> 当一个生成式系统失去部分外部观测约束时，它的内部世界模型会如何演化？

更具体地说：

1. 系统是否会逐渐偏离原来的外部环境？
2. 系统是否会混合来自不同情境的记忆、对象和规则？
3. 某些高频出现或高价值的内容，是否更容易出现在自由生成的轨迹中？
4. 系统是否会产生违反当前环境规则、但符合另一个情境规则的行为？
5. 当真实观测重新恢复后，系统能否回到原来的状态？
6. 开环或退锚阶段的漂移，能否反映模型对自身预测的不确定性？

梦中“把谷子寄到现实地址”的行为，可以被抽象为一种：

> **跨情境泄漏（cross-context leakage）**

也就是说，系统在情境 A 中调用了情境 B 的对象、地址、目标或行动规则，并试图构造一条原本不存在的跨情境因果路径。
